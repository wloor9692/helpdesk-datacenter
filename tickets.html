Descripción del problema
El servidor SRV-DB-01 dejó de responder consultas a las 08:25. Los servicios de MySQL y PostgreSQL no inician. El error en log indica corrupción de tablespace.
Solución aplicada
Se realizó recuperación de tablespace corrupto mediante respaldo de las 03:00 AM. Se reiniciaron los servicios de base de datos. Se validó integridad de datos con el administrador.

Descripción del problema
El switch de distribución SW-DIST-02 perdió conectividad con los switches de acceso en el piso 2, dejando sin red a 35 estaciones de trabajo.
Solución aplicada
Se identificó puerto SFP+ con fallo en módulo óptico. Se reemplazó el módulo y se restauraron las conexiones troncales. Se verificó la convergencia del protocolo STP.
